0.1 Primeira versão, grátis e open source

Veja o que ocupa o seu disco. Em instantes.

O Driveleaf é um analisador de espaço em disco grátis e open source para Windows. Ele lê a Master File Table do NTFS diretamente, então até uma unidade cheia é analisada em instantes, e mostra tudo como um treemap que você explora com cliques.

Recursos

Tudo o que você precisa para liberar espaço no disco, e nada além

Escolha uma unidade, clique em Analisar, e as maiores pastas e arquivos aparecem na hora. Clique para selecionar, dê dois cliques para entrar, use o botão direito para ações.

Analisa em instantes

Com permissão de administrador, o Driveleaf lê a Master File Table em paralelo, em vez de abrir pasta por pasta. Uma unidade com meio milhão de arquivos leva cerca de um terço de segundo.

Funciona sem administrador

Sem permissão elevada, ele percorre as pastas em paralelo. É assim também que lê unidades exFAT, ReFS, USB e de rede.

Bate com o disco

Hard links contam uma vez, arquivos compactados e esparsos contam o que realmente ocupam, e os metadados do sistema de arquivos ficam numa pasta própria.

Um treemap que acompanha

Até 200 mil quadrados desenhados com WebGL2, os maiores com nome, e zoom suave em qualquer pasta. A cor mostra o tipo de arquivo num relance.

Encontra qualquer coisa

Os maiores arquivos da unidade, o espaço de cada tipo de arquivo e Ctrl+K para buscar qualquer nome em milissegundos.

Cuidadoso com seus arquivos

Ele só lê, a não ser que você peça. Remover manda para a Lixeira, sempre depois de uma confirmação, e arquivos do sistema são recusados.

Como funciona

Por que o Driveleaf é rápido

A maioria dos analisadores de disco pede ao Windows o conteúdo de cada pasta, uma de cada vez. O Driveleaf vai direto à fonte.

Lê o índice, não as pastas

O NTFS guarda um registro de cada arquivo na sua Master File Table. O Driveleaf lê essa tabela em blocos grandes, em várias threads ao mesmo tempo, e monta a árvore inteira a partir dela.

Conta o que é usado de verdade

Os tamanhos vêm dos clusters que cada arquivo ocupa. Num disco real de 534 GB, o total fica a 0,12% do espaço usado que o NTFS informa.

Explora pela GPU

O treemap é calculado em Rust e desenhado pela placa de vídeo, então o zoom e o passar do mouse continuam fluidos mesmo com centenas de milhares de quadrados.

Medido, não prometido. Todos os números desta página vêm dos benchmarks publicados, com os scripts para reproduzi-los.

Privacidade e segurança

Seus arquivos continuam seus

Um analisador de disco vê o nome de todos os seus arquivos. O Driveleaf mantém tudo isso no seu computador.

  • Nenhuma conexão de redeSem telemetria, sem checagem de atualização e sem conteúdo remoto, garantido por uma política de segurança de conteúdo rígida.
  • Só leitura por padrãoNada é apagado sozinho. Remover manda para a Lixeira, depois que você confirma.
  • Protege o sistemaArquivos do Windows, o arquivo de paginação e os metadados do sistema de arquivos não podem ser removidos pelo app.
  • Aberto para inspeçãoCada linha está no GitHub. O parser trata o disco como entrada não confiável e passa por testes de fuzzing.

Para desenvolvedores

O motor é seu para reutilizar

O scanner é escrito em Rust e não depende da interface. Use pela linha de comando ou como crates nas suas próprias ferramentas.

driveleaf-cli scan C: --format json

# O parser da MFT no seu projeto
cargo add driveleaf-ntfs

Perguntas

Perguntas frequentes

O Driveleaf é grátis?

Sim. O Driveleaf é grátis e open source, sob a licença MIT ou Apache-2.0, para uso pessoal e comercial, sem anúncios e sem conta.

O Driveleaf precisa de permissão de administrador?

Não. Com permissão de administrador ele lê a Master File Table do NTFS, que é o modo rápido. Sem ela, percorre as pastas em paralelo, o que também cobre exFAT, ReFS e unidades de rede. O app oferece reabrir como administrador quando isso ajuda.

O Driveleaf pode apagar meus arquivos?

Só quando você pede. O Driveleaf apenas lê a unidade. Remover um item manda para a Lixeira depois de uma confirmação, e arquivos do sistema são recusados.

Como o Driveleaf se compara ao WizTree, WinDirStat e TreeSize?

Todos mostram onde está o espaço do disco. O Driveleaf lê a Master File Table do NTFS, como o WizTree, e é isso que faz uma análise completa levar instantes. Ele é open source e grátis para qualquer uso, inclusive no trabalho.

O Driveleaf envia algum dado?

Não. O app não faz nenhuma conexão de rede: sem telemetria, sem checagem de atualização e sem conteúdo remoto.

Quais versões do Windows o Driveleaf suporta?

Windows 10 e Windows 11, 64 bits. O modo rápido funciona em unidades NTFS, e as demais são analisadas pasta por pasta.
