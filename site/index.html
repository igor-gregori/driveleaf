Features

Everything you need to free up disk space, nothing you don't

Pick a drive, press Scan, and the biggest folders and files are right there. Click to select, double-click to zoom in, right-click for actions.

Scans in moments

With administrator rights, Driveleaf reads the Master File Table in parallel instead of opening every folder. A drive with half a million files takes about a third of a second.

Works without admin rights

No elevation? It walks the folders in parallel instead. That is also how it reads exFAT, ReFS, USB and network drives.

Adds up to the disk

Hard links count once, compressed and sparse files count what they really occupy, and the file system's own metadata gets its own folder.

A treemap that keeps up

Up to 200,000 tiles drawn with WebGL2, the largest ones named, and smooth zoom into any folder. Color tells you the file type at a glance.

Finds anything

The largest files on the drive, the space each file type takes, and Ctrl+K to search every name in milliseconds.

Careful with your files

It only reads, unless you ask. Removing goes to the Recycle Bin, always after a confirmation, and system files are refused.

How it works

Why Driveleaf is fast

Most disk analyzers ask Windows for the contents of each folder, one folder at a time. Driveleaf goes to the source.

Read the index, not the folders

NTFS keeps a record of every file in its Master File Table. Driveleaf reads that table in large blocks, on several threads at once, and builds the whole tree from it.

Count what is really used

Sizes come from the clusters each file occupies. On a real 534 GB drive, the total lands within 0.12% of what NTFS reports as used.

Explore it on the GPU

The treemap is laid out in Rust and drawn by your graphics card, so zooming and hovering stay fluid even with hundreds of thousands of tiles.

Privacy and safety

Your files stay yours

A disk analyzer sees the name of every file you have. Driveleaf keeps all of it on your computer.

  • No network connectionsNo telemetry, no update check and no remote content, held to that by a strict content security policy.
  • Read-only by defaultNothing is ever deleted on its own. Removing sends to the Recycle Bin, after you confirm.
  • Guards the systemWindows files, the page file and the file system's metadata cannot be removed from the app.
  • Open to inspectionEvery line is on GitHub. The parser treats the disk as untrusted input and is fuzz tested.

For developers

The engine is yours to reuse

The scanner is written in Rust and has no GUI dependency. Use it from the command line, or as crates in your own tools.

# Every file on C:, as JSON or CSV
driveleaf-cli scan C: --format json

# The MFT parser in your own project
cargo add driveleaf-ntfs

FAQ

Questions, answered

Is Driveleaf free?

Yes. Driveleaf is free and open source under the MIT or Apache-2.0 license, for personal and commercial use, with no ads and no account.

Does Driveleaf need administrator rights?

No. With administrator rights it reads the NTFS Master File Table, which is the fast mode. Without them it walks the folders in parallel, which also covers exFAT, ReFS and network drives. The app offers to reopen as administrator when it would help.

Can Driveleaf delete my files?

Only when you ask. Driveleaf only reads your drive. Removing an item sends it to the Recycle Bin after a confirmation, and system files are refused.

How does Driveleaf compare with WizTree, WinDirStat and TreeSize?

All of them show where your disk space goes. Driveleaf reads the NTFS Master File Table, as WizTree does, which is what makes a full scan take moments. It is open source and free for any use, including at work.

Does Driveleaf send any data?

No. The app makes no network connections: no telemetry, no update check and no remote content.

Which versions of Windows does Driveleaf support?

Windows 10 and Windows 11, 64-bit. The fast mode works on NTFS drives, and every other drive is scanned folder by folder.
