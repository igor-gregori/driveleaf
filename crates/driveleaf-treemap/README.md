# driveleaf-treemap

Squarified treemap layout, part of [Driveleaf](https://driveleaf.app), a fast,
open-source disk space analyzer for Windows.

The squarified treemap algorithm of Bruls, Huizing and van Wijk, plus a nested
layout for whole trees that opens the largest folders first within a tile
budget. It has no GUI dependency and writes a compact binary tile format.

See the [repository](https://github.com/igor-gregori/driveleaf) for the architecture notes and benchmarks.
