# driveleaf-core

Disk usage model and scanners, part of [Driveleaf](https://driveleaf.app), a fast,
open-source disk space analyzer for Windows.

Turns an MFT scan, or a parallel folder walk, into a compact tree of a whole
drive, with folder totals that add up to the disk, and answers the queries a
disk analyzer needs: children by size, largest files, space per file type and
name search.

See the [repository](https://github.com/igor-gregori/driveleaf) for the architecture notes and benchmarks.
