# driveleaf-win

Windows calls for Driveleaf, part of [Driveleaf](https://driveleaf.app), a fast,
open-source disk space analyzer for Windows.

Volume listing, fast directory enumeration, elevation, and shell actions such as
revealing in Explorer, file properties and sending to the Recycle Bin. On other
platforms the crate is empty.

See the [repository](https://github.com/igor-gregori/driveleaf) for the architecture notes and benchmarks.
