# driveleaf-cli

Command line for the Driveleaf scan engine, part of [Driveleaf](https://driveleaf.app), a fast,
open-source disk space analyzer for Windows.

Scans a drive, a folder or a volume image and prints every entry as CSV or JSON:
`driveleaf-cli scan C: --format json`. Run `driveleaf-cli` alone to see every
command.

See the [repository](https://github.com/igor-gregori/driveleaf) for the architecture notes and benchmarks.
